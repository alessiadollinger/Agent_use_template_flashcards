# Vocab Flashcards

A small single-page website to add English–German word pairs and practise them as flashcards. All data is saved in the browser (localStorage). Built with plain HTML, CSS and JavaScript, step by step with GitHub Copilot.

## How to open
Open `index.html` in a browser (double-click the file or use the Live Server extension in VS Code). No installation needed.

## Features
- Add a word pair (English + German); empty fields can't be submitted
- List of all saved word pairs
- Delete a word pair
- Pairs are saved and still there after reloading the page
- Practice mode: shows an English word, click the card to reveal the German word
- "Next" shows a random different card
- "I knew it" counter for the current session

## Project files
- `SPEC.md` – what to build (and what not)
- `AGENTS.md` – rules for Copilot
- `PROGRESS.md` – steps done and decisions
